# Change: Add play-by-play filters and period tabs

## Why
The play-by-play list is useful but hard to scan. Filters and period tabs help users find goals, penalties, and shots quickly.

## What Changes
- Add period tabs to filter play-by-play by period.
- Add event-type filters (Goals, Penalties, Shots, All).

## Impact
- Affected specs: scores-view (modified)
- Affected code: resources/js/Pages/LabScoreDetail.tsx, resources/js/lib/nhl.ts
