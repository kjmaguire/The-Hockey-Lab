## ADDED Requirements
### Requirement: Play-by-play supports period tabs
The game detail page SHALL allow filtering play-by-play events by period.

#### Scenario: Period filter
- **WHEN** a user selects a period tab
- **THEN** only events for that period are shown.

### Requirement: Play-by-play supports event filters
The game detail page SHALL allow filtering play-by-play events by event type.

#### Scenario: Goal filter
- **WHEN** a user selects the Goals filter
- **THEN** only goal events are shown.

#### Scenario: Penalty filter
- **WHEN** a user selects the Penalties filter
- **THEN** only penalty events are shown.

#### Scenario: Shot filter
- **WHEN** a user selects the Shots filter
- **THEN** only shot events are shown.

#### Scenario: Reset filter
- **WHEN** a user selects All
- **THEN** all play-by-play events are shown.
